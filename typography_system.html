01 · Typefaces

Three fonts. One voice.

OffTheBoot uses three typefaces. Newsreader carries the brand's warmth and humanity — it appears in every heading. Source Sans 3 is the body and UI voice — body, UI, labels, buttons. Satisfy is reserved for the logo wordmark only. The contrast between them creates the visual tension that makes the site memorable.

Italy off the beaten path.
An elegant editorial serif with crisp, literary contrast that feels warm and considered. One weight only — 600 — which enforces consistency. The visual weight comes from size and tracking, not extra font weights.

Why this trio? Newsreader communicates warmth, authenticity and place — qualities central to OffTheBoot's identity. Source Sans 3 is the body and UI voice — clean, highly legible, with proper italics for editorial accents. Satisfy (logo only) gives the wordmark a distinctive handwritten signature. Together they keep the brand warm, clear and human.

Letter spacing rule: Large text (40px+) always gets negative tracking (-0.01 to -0.02em) — this pulls the letters together and adds visual weight. Small uppercase labels (10–12px) always get wide positive tracking (+0.12 to +0.18em) — uppercase letters are designed for lower tracking and need extra space to breathe at small sizes. Body text always stays at 0.

03 · CSS Tokens

Implementation

Add the Google Fonts import to your document head, then paste the typography tokens into your globals.css. Use these variables everywhere — never hardcode font-family, font-size, or letter-spacing values directly.

Document <head> — Google Fonts import
<link href="https://fonts.googleapis.com/css2?family=Newsreader:ital,wght@0,600;1,600
&family=Source+Sans+3:ital,wght@0,400;0,500;0,600;0,700;1,400
&family=Satisfy&display=swap"
rel="stylesheet">
globals.css — typography tokens
/* ── OffTheBoot Typography System v2.0 "Abete" ── */
:root {

  /* Font families */
  --font-display: 'Newsreader', Georgia, serif;
  --font-body: 'Source Sans 3', system-ui, -apple-system, sans-serif;
  --font-logo: 'Satisfy', 'Brush Script MT', cursive; /* logo wordmark only */

  /* Font sizes — Hero to Label */
  --text-hero: 4.25rem;    /* 68px — hero display */
  --text-h1: 2.75rem;   /* 44px — section heading */
  --text-h2: 2rem;    /* 32px — sub-section */
  --text-h3: 1.375rem; /* 22px — accent italic */
  --text-body: 1.0625rem; /* 17px — body */
  --text-ui: 0.9375rem; /* 15px — UI text */
  --text-label: 0.8125rem; /* 13px — labels */
  --text-xs: 0.6875rem; /* 11px — overlines */

  /* Line heights */
  --lh-tight: 1.0;    /* hero titles */
  --lh-snug: 1.15;   /* h2, h3 */
  --lh-normal: 1.5;   /* UI text */
  --lh-relaxed: 1.75;  /* body, descriptions */
  --lh-loose: 1.9;   /* blog long-form */

  /* Letter spacing */
  --ls-tight: -0.02em;  /* hero, h1 */
  --ls-snug: -0.01em;  /* h2 */
  --ls-normal: 0em;    /* body, UI */
  --ls-wide: 0.12em;   /* labels, buttons */
  --ls-wider: 0.18em;  /* overlines */

  /* Font weights — Source Sans 3 only (Newsreader always 600; Satisfy logo-only at 400) */
  --fw-light: 400;    /* body text (300 not loaded) */
  --fw-regular: 400;   /* nav links */
  --fw-medium: 500;   /* UI text */
  --fw-semibold: 600;  /* buttons */
  --fw-bold: 700;    /* labels, badges */

}

/* ── Applied styles ── */
h1, h2, h3, h4, .display {
  font-family: var(--font-display);
  font-weight: 600; /* Newsreader — single display weight */
}

body, p, span, a, button, input {
  font-family: var(--font-body);
}

.hero-title {
  font-family: var(--font-display);
  font-size: var(--text-hero);
  line-height: var(--lh-tight);
  letter-spacing: var(--ls-tight);
}

.section-label {
  font-family: var(--font-body);
  font-size: var(--text-xs);
  font-weight: var(--fw-bold);
  letter-spacing: var(--ls-wider);
  text-transform: uppercase;
}

05 · Rules of use

What to do and what to avoid

These rules protect the typographic integrity of the brand. Violations make the site feel inconsistent and unprofessional.

✓
Always use negative tracking on large Newsreader
Italy off the beaten path.
letter-spacing: -0.02em ✓
At 40px and above, always apply -0.01em to -0.02em. The letters pull together and the title gains visual weight and authority.
✗
Never use Newsreader for body text
Italians who left, travelled 50 countries, and came back with different eyes. We show you the Italy most Italians don't even know.
Newsreader as body text ✗
Newsreader is not optimised for long-form reading at small sizes. It loses legibility below 18px. Body text must always be Source Sans 3.
✓
Use Source Sans 3 400 for body copy
Away from the crowds. We show you the real Italy — away from the tourist traps and Instagram hotspots.
font-weight: 400 ✓
Source Sans 3 (400) creates strong contrast with the visual weight of Newsreader headings. Its open, humanist shapes keep long-form copy clear and easy to read at small sizes.
✗
Never use Source Sans 3 for headings
Italy off the beaten path.
Source Sans 3 as heading ✗
Source Sans 3 headings would erase Newsreader's editorial weight. The entire character of the brand depends on Newsreader being the face of every title. No exceptions.
✓
Wide tracking on all uppercase Source Sans 3 labels
Northeast Italy · Slow travel
Custom itinerary
letter-spacing: 0.12–0.18em ✓
Uppercase letters need room to breathe at small sizes. Always pair text-transform: uppercase with letter-spacing of at least 0.12em.
✗
Never introduce a third typeface
A third serif font in headings ✗
A different sans-serif for body ✗
Third font — never ✗
Three fonts is the maximum. Adding a fourth creates visual noise, slows page load, and dilutes brand identity. If a use case isn't covered by Newsreader, Source Sans 3, or the .logo-wordmark (Satisfy), solve it with weight and size — not a new font.
✓
Use Newsreader italic for pull quotes and accents
"Slow. Local. Real."
The italic variant of Newsreader is expressive and distinctive. Reserve it for pull quotes, testimonials, H3 sub-headings, and moments where personality matters most.
✓
Logo always in Satisfy (wordmark only)
OffTheBoot
OffTheBoot
OffTheBoot
The wordmark uses Satisfy (weight 400) via the .logo-wordmark utility, in navbar and footer. It works on all three background colours. Never use Satisfy for anything other than the wordmark — never headings, body, nav links, or UI.
