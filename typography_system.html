01 · Typefaces

Two fonts. One voice.

OffTheBoot uses exactly two typefaces. Young Serif carries the brand's warmth, character and humanity — it appears in every heading and display element. Geist handles everything functional — body text, UI, labels, buttons. The contrast between them creates the visual tension that makes the site memorable.

Display & Headings
Young Serif
Italy off the beaten path.
A serif with rounded, almost cartoonish curves that feel warm, organic and handcrafted. One weight only — regular 400 — which enforces consistency. The visual weight comes from size and tracking, not font weight.

Why these two? Young Serif communicates warmth, authenticity and place — qualities central to OffTheBoot's identity. Geist communicates precision, clarity and modernity — qualities needed in a digital product. The contrast between a rounded serif and a geometric sans creates visual tension that keeps the eye engaged. Neither font alone would capture the full brand.

02 · Type scale

Seven levels of hierarchy

Every text element on the site belongs to one of these seven levels. Never introduce sizes outside this scale. The scale is built on a 1.25 ratio — each step is 25% larger than the previous.

Letter spacing rule: Large text (40px+) always gets negative tracking (-0.01 to -0.02em) — this pulls the letters together and adds visual weight. Small uppercase labels (10–12px) always get wide positive tracking (+0.12 to +0.18em) — uppercase letters are designed for lower tracking and need extra space to breathe at small sizes. Body text always stays at 0.

03 · CSS Tokens

Implementation

Add the Google Fonts import to your document head, then paste the typography tokens into your globals.css. Use these variables everywhere — never hardcode font-family, font-size, or letter-spacing values directly.

Document <head> — Google Fonts import
<link href="https://fonts.googleapis.com/css2?family=Young+Serif:ital@0;1
&family=Geist:wght@300;400;500;600;700&display=swap"
rel="stylesheet">
globals.css — typography tokens
/* ── OffTheBoot Typography System v1.0 ── */
:root {

  /* Font families */
  --font-display: 'Young Serif', Georgia, serif;
  --font-body: 'Geist', system-ui, sans-serif;

  /* Font sizes — Hero to Label */
  --text-hero: 4rem;    /* 64px — hero display */
  --text-h1: 2.5rem;   /* 40px — section heading */
  --text-h2: 1.75rem;  /* 28px — sub-section */
  --text-h3: 1.25rem;  /* 20px — accent italic */
  --text-body: 1rem;    /* 16px — body */
  --text-ui: 0.875rem; /* 14px — UI text */
  --text-label: 0.75rem;  /* 12px — labels */
  --text-xs: 0.625rem; /* 10px — overlines */

  /* Line heights */
  --lh-tight: 1.0;    /* hero titles */
  --lh-snug: 1.15;   /* h2, h3 */
  --lh-normal: 1.5;   /* UI text */
  --lh-relaxed: 1.75;  /* body, descriptions */
  --lh-loose: 1.9;   /* blog long-form */

  /* Letter spacing */
  --ls-tight: -0.02em;  /* hero, h1 */
  --ls-snug: -0.01em;  /* h2 */
  --ls-normal: 0em;    /* body, UI */
  --ls-wide: 0.12em;   /* labels, buttons */
  --ls-wider: 0.18em;  /* overlines */

  /* Font weights — Geist only */
  --fw-light: 300;    /* body text */
  --fw-regular: 400;   /* nav links */
  --fw-medium: 500;   /* UI text */
  --fw-semibold: 600;  /* buttons */
  --fw-bold: 700;    /* labels, badges */

}

/* ── Applied styles ── */
h1, h2, h3, h4, .display {
  font-family: var(--font-display);
  font-weight: 400; /* Young Serif has one weight */
}

body, p, span, a, button, input {
  font-family: var(--font-body);
}

.hero-title {
  font-family: var(--font-display);
  font-size: var(--text-hero);
  line-height: var(--lh-tight);
  letter-spacing: var(--ls-tight);
}

.section-label {
  font-family: var(--font-body);
  font-size: var(--text-xs);
  font-weight: var(--fw-bold);
  letter-spacing: var(--ls-wider);
  text-transform: uppercase;
}

05 · Rules of use

What to do and what to avoid

These rules protect the typographic integrity of the brand. Violations make the site feel inconsistent and unprofessional.

✓
Always use negative tracking on large Young Serif
Italy off the beaten path.
letter-spacing: -0.02em ✓
At 40px and above, always apply -0.01em to -0.02em. The letters pull together and the title gains visual weight and authority.
✗
Never use Young Serif for body text
Italians who left, travelled 50 countries, and came back with different eyes. We show you the Italy most Italians don't even know.
Young Serif as body text ✗
Young Serif is not optimised for long-form reading at small sizes. It loses legibility below 18px. Body text must always be Geist.
✓
Use Geist 300 (Light) for body copy
Away from the crowds. We show you the real Italy — away from the tourist traps and Instagram hotspots.
font-weight: 300 ✓
Geist Light (300) creates strong contrast with the visual weight of Young Serif headings. It also reads as more refined and less corporate than Regular (400).
✗
Never use Geist for headings
Italy off the beaten path.
Geist as heading ✗
Geist headings look like a generic tech website. The entire character of the brand depends on Young Serif being the face of every title. No exceptions.
✓
Wide tracking on all uppercase Geist labels
Northeast Italy · Slow travel
Custom itinerary
letter-spacing: 0.12–0.18em ✓
Uppercase letters need room to breathe at small sizes. Always pair text-transform: uppercase with letter-spacing of at least 0.12em.
✗
Never introduce a third typeface
A third serif font in headings ✗
A different sans-serif for body ✗
Third font — never ✗
Two fonts is the maximum. Adding a third creates visual noise, slows page load, and dilutes brand identity. If a use case isn't covered by Young Serif or Geist, solve it with weight and size — not a new font.
✓
Use Young Serif italic for pull quotes and accents
"Slow. Local. Real."
The italic variant of Young Serif is expressive and distinctive. Reserve it for pull quotes, testimonials, H3 sub-headings, and moments where personality matters most.
✓
Logo always in Young Serif regular
Off the Boot

The wordmark is Young Serif regular at the navbar size (approximately 16–18px). It works on all three background colours. Never bold, never italic, never Geist.
