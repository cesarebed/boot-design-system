01 · Core palette

The six core colours

These six colours form the identity of OffTheBoot. Every element of the site uses only these colours — or the tints derived from them. Do not introduce any colour outside this set without explicit approval.

Abete
#1E2A1A
Primary brand colour
Dark fir green. Structural elements, dark strips, hero sections, primary buttons, accent-on-light, footer accents.
Oro
#D6AE5C
Accent colour
Gold. Price/duration badge BACKGROUNDS only — always with Ink text on top. Never used as text on white.
Bordeaux
#9B3940
CTA colour
Call-to-action buttons only (hover #7E2E34). Use sparingly — one CTA per section maximum.
Nero bosco
#131C10
Text & dark background
All body text, headings, the darkest section backgrounds, footer background. The primary text colour.
Lino
#E8E2D2
Cream text on dark
Cream text on dark backgrounds ONLY — never a surface, except the one "Plan my trip" pricing strip which uses Lino as its background.
Off-white
#FCFCFC
Background
Page backgrounds, light sections, card backgrounds, form inputs. A clean off-white — never pure #ffffff.

Why these six? Each colour maps directly to a brand value. Abete = nature and territory. Oro = local traditions and craft. Bordeaux = human warmth and Italian heritage. Nero bosco = depth and authenticity. Lino = history and slowness. Off-white = clarity and openness. No colour in this palette is arbitrary.

02 · Tints

Extended tints

Three light fir/sage tints derived from Abete. Used exclusively as section backgrounds, badge fills, step circles, and decorative surfaces. Never as text colour or on interactive elements. The retired v1 yellow and green tint families are gone.

Fir / sage tints — from Abete
Fir mist
Fir mist
#E6EADB
Lightest fir. Category/style badge backgrounds, step-number circles, image placeholders. Subtle hover states.
Light fir
Light fir
#DEE4D6
Light section backgrounds, newsletter, feature/values blocks, blog TL;DR. The primary light section colour.
Sage
Sage
#A8BE97
Accents on dark backgrounds — hero italic, dots, dark-CTA accents. Do not use as a text background at small sizes.

Tint rule: Tints are backgrounds, never foregrounds. Never use a tint colour as text. Always use Nero bosco (#131C10) for text placed on any tint background — the contrast is guaranteed to pass AAA on all three tints.

03 · CSS Tokens

Implementation

Copy this block into your global CSS file. Use the variable names everywhere in your codebase — never hardcode hex values directly. This ensures a single point of change if any colour needs updating.

globals.css · paste at the top of your stylesheet
/* ── OffTheBoot Colour System v2.0 "Abete" ── */
:root {

  /* Core palette */
  
--color-primary:     #1E2A1A; /* Abete */
  
--color-accent:      #D6AE5C; /* Oro */
  
--color-cta:         #9B3940; /* Bordeaux */
  
--color-ink:         #131C10; /* Nero bosco */
  
--color-parchment:   #E8E2D2; /* Lino */
  
--color-bg:          #FCFCFC; /* Off-white */
  
--color-muted:       #6B6457; /* Muted */
  
--color-border:      #E4E5DF; /* Light border */
  
--color-border-strong: #D6D7CF; /* Strong border */

  /* Fir / sage tints (names kept --color-teal-* in code) */
  
--color-teal-mist:  #E6EADB; /* Fir mist */
  
--color-teal-pale:  #DEE4D6; /* Light fir */
  
--color-teal-soft:  #A8BE97; /* Sage */

}

How to use in code — examples:

/* ✓ Correct — always use variables */
.btn-cta { background: var(--color-cta); color: white; }
.section-light { background: var(--color-teal-pale); }
.badge-category { background: var(--color-teal-mist); color: var(--color-primary); }

/* ✗ Never hardcode hex values */
.btn-cta { background: #9B3940; } /* don't do this */

05 · Accessibility

Colour blindness

Approximately 8% of men and 0.5% of women experience some form of colour vision deficiency. The palette has been tested across four conditions. Key finding: the primary/CTA pair is manageable but should always be reinforced with shape and text labels.

Deuteranopia
Green-red · ~6% of men
Abete and Bordeaux both read as deep, dark tones, well separated by luminance from Oro. Always pair the CTA button with a clear text label and distinct shape — not colour alone.
Protanopia
Red weakness · ~2% of men
Similar to deuteranopia. Oro remains clearly distinct. The Abete/Bordeaux pair has acceptable luminance separation. Use text labels on all interactive elements.
Tritanopia
Blue-yellow · very rare
The palette performs well. All six colours remain distinguishable. Oro shifts slightly but remains separate from Abete and Bordeaux.
Achromatopsia
Greyscale only · very rare
Abete (~62/255) is darker than Bordeaux (~94/255) — a clear luminance difference. Oro (~176/255) and Lino (~227/255) are well separated. Good overall greyscale hierarchy.

Universal design rule: Never rely on colour alone to communicate meaning. Every interactive element (button, link, form field) must be identifiable by shape, text, or position — independent of colour perception. This benefits not just colour blind users but also anyone on low-quality screens or in bright sunlight.
