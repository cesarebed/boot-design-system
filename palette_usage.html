01 · Core palette

The six core colours

These six colours form the identity of OffTheBoot. Every element of the site uses only these colours — or the tints derived from them. Do not introduce any colour outside this set without explicit approval.

Forest Teal
#2E5855
Primary brand colour
Navbar, hero sections, primary buttons, footer accents, section dividers.
Stone Gold
#C4920A
Accent colour
Price badges, highlight labels, section accent tags, map markers. Always with Ink text on top.
Terracotta
#D4701A
CTA colour
Primary call-to-action buttons only. Active links, selected states. Use sparingly — one CTA per section maximum.
Ink
#1E1C16
Text & dark background
All body text, headings, hero dark backgrounds, footer background. The primary text colour.
Parchment
#EDE5D0
Surface & borders
Alternate section backgrounds, card borders, image placeholders, dividers. Warm neutral base.
Warm White
#FAFAF4
Background
Page backgrounds, card backgrounds, form inputs. Slightly warm — not pure white — to feel organic and human.

Why these six? Each colour maps directly to a brand value. Forest Teal = nature and territory. Stone Gold = local traditions and craft. Terracotta = human warmth and Italian heritage. Ink = depth and authenticity. Parchment = history and slowness. Warm White = clarity and openness. No colour in this palette is arbitrary.

Tint rule: Tints are backgrounds, never foregrounds. Never use a tint colour as text. Always use Ink (#1E1C16) for text placed on any tint background — the contrast is guaranteed to pass AAA on all eight tints.

03 · CSS Tokens

Implementation

Copy this block into your global CSS file. Use the variable names everywhere in your codebase — never hardcode hex values directly. This ensures a single point of change if any colour needs updating.

globals.css · paste at the top of your stylesheet
/* ── OffTheBoot Colour System v1.0 ── */
:root {

  /* Core palette */
  
--color-primary:     #2E5855; /* Forest Teal */
  
--color-accent:      #C4920A; /* Stone Gold */
  
--color-cta:         #D4701A; /* Terracotta */
  
--color-ink:         #1E1C16; /* Ink */
  
--color-parchment:   #EDE5D0; /* Parchment */
  
--color-bg:          #FAFAF4; /* Warm White */

  /* Yellow tints */
  
--color-yellow-butter: #FDF5CC;
  
--color-yellow-straw:  #F8EDA0;
  
--color-yellow-wheat:  #F5E8A8;
  
--color-yellow-pollen: #EDD878;

  /* Green tints */
  
--color-green-mist:    #EAF3EC;
  
--color-green-sage:    #D8ECD8;
  
--color-green-fern:    #C0DEC0;
  
--color-green-meadow:  #9AC49A;

}

How to use in code — examples:

/* ✓ Correct — always use variables */
.btn-primary { background: var(--color-cta); color: white; }
.section-journal { background: var(--color-yellow-wheat); }
.badge-category { background: var(--color-green-mist); color: var(--color-primary); }

/* ✗ Never hardcode hex values */
.btn-primary { background: #D4701A; } /* don't do this */

05 · Accessibility

Colour blindness

Approximately 8% of men and 0.5% of women experience some form of colour vision deficiency. The palette has been tested across four conditions. Key finding: the primary/CTA pair is manageable but should always be reinforced with shape and text labels.

Deuteranopia
Green-red · ~6% of men
Forest Teal and Terracotta shift toward similar brownish-green tones. Always pair the CTA button with a clear text label and distinct shape — not colour alone.
Protanopia
Red weakness · ~2% of men
Similar to deuteranopia. Stone Gold remains clearly distinct. The primary/CTA pair has acceptable luminance separation. Use text labels on all interactive elements.
Tritanopia
Blue-yellow · very rare
The palette performs well. All six colours remain distinguishable. Stone Gold shifts slightly but remains separate from Forest Teal.
Achromatopsia
Greyscale only · very rare
Forest Teal (~88/255) is darker than Terracotta (~124/255) — a clear luminance difference. Stone Gold (~154/255) and Parchment (~222/255) are well separated. Good overall greyscale hierarchy.

Universal design rule: Never rely on colour alone to communicate meaning. Every interactive element (button, link, form field) must be identifiable by shape, text, or position — independent of colour perception. This benefits not just colour blind users but also anyone on low-quality screens or in bright sunlight.
